Privacy Policy

Last updated: March 2026

GitLab Job Starter is a browser extension that helps you automatically start manual CI jobs on GitLab pipeline pages.

Data We Collect

We collect no personal data. The extension stores only:

  • Job name patterns and groups — strings you type into the extension popup to identify CI jobs. These are stored locally in your browser using chrome.storage.sync and synced across your own Chrome profile. They are never sent to any external server.

Network Requests

The extension makes requests exclusively to GitLab instances that you are already logged into and actively browsing. Specifically, it calls the GitLab REST API (/api/v4/) to retrieve pipeline job information, and the job play endpoint (/-/jobs/:id/play.json) to start manual jobs on your behalf. These requests use your existing browser session — no credentials are stored by the extension.

No data is sent to the extension developer or any third party.

Permissions

The extension requests access to all URLs (*://*/*) so that it can function on any self-hosted or cloud GitLab instance, not just a single hardcoded domain. It only activates on pages matching */-/pipelines/*.

Contact

If you have questions about this policy, please open an issue on the project's GitHub repository.
